Koidoro isometric garden

Vietnamese trees, ponds, dogs and cats, built from small cubes on plots of land and drawn in code with no image files. This is a sample garden, so you can see how yours would look.

Break session

Select a tree to water it. On a keyboard, tab into the garden, use the arrow keys to move between trees, and press Enter to water.

Work session

Choose your tree, then start

A tree only reaches Mature if the session runs to 00:00. Abandon it earlier and it stays at its current stage.

How the garden behaves

Choosing a tree
You pick one of the six before each Work session. The sample garden above uses a random mix.
Where trees go
Each tree takes the next plot in a square spiral out from the centre. Once planted, it never moves.
Decorations
Some plots along the spiral hold a pond, rocks, a meadow or a buffalo. They arrive by themselves as the garden grows.
Dogs and cats
Each pet arrives once, by itself, and stays in its spot on the grass at the front of the garden, wagging, blinking and looking around. As the garden grows, pets settle further out, so trees never hide them.
Other animals
Empty plots
Grass plots surround the trees, so the edge of the garden stays soft as it grows.
Big gardens
The garden shrinks to fit the screen. Once a plot would be narrower than 28 pixels, it scrolls sideways instead.
Watering
A watering can pours over the tree and the soil darkens for a moment, then fades. Nothing about the tree changes.

All of this is sample art and sample data, generated from the same code each time.
